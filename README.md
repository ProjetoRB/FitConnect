# FitConnect

O FitConnect é um sistema desenvolvido para gerenciamento de treinos e acompanhamento físico. O projeto possui uma aplicação mobile, uma interface web e uma API em Java integrada ao banco de dados MySQL.

## Objetivo

O sistema busca facilitar o acompanhamento de treinos, o monitoramento da evolução dos usuários e a organização das informações relacionadas às atividades físicas.

## Tecnologias Utilizadas

* Java
* Android Studio
* MVVM
* Retrofit
* MySQL
* HTML
* CSS

## Funcionalidades

* Gerenciamento de treinos
* Acompanhamento físico dos usuários
* Integração com API REST
* Interface web para visualização de dados
* Aplicativo mobile para acesso às informações

## Desenvolvedores

Projeto desenvolvido em equipe como parte de atividades acadêmicas.
